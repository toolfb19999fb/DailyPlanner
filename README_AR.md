# برنامجي اليومي — Android

تطبيق Android خفيف وشخصي لإدارة برنامج يومي متكرر.

## الوظائف
- إضافة مهمة مع وقت محدد.
- المهمة تتكرر يومياً.
- إشعار في الوقت المحدد.
- إذا فتحت الهاتف بعد وقت المهمة ولم يصلك التنبيه (مثلاً بسبب وضع توفير البطارية)، يظهر تذكير عند فتح الهاتف.
- تعليم المهمة كمكتملة لليوم.
- حذف المهام.
- إعادة جدولة التنبيهات بعد إعادة تشغيل الهاتف.
- لا يحتاج إنترنت ولا حساب.

## ملاحظات Android
- عند أول تشغيل، اسمح للتطبيق بإرسال الإشعارات.
- اسمح بالتنبيهات الدقيقة (Exact alarms) إذا طلبها Android حتى تكون المواعيد أقرب للوقت المحدد.
- بعض الهواتف مثل Xiaomi/OPPO/Realme قد تحتاج السماح للتطبيق بالعمل في الخلفية وتعطيل Battery Optimization حتى لا يمنع النظام التنبيهات.

## إخراج APK
1. ثبّت Android Studio على الكمبيوتر.
2. افتح مجلد `DailyPlanner`.
3. انتظر حتى يكتمل Gradle Sync.
4. من القائمة: Build > Build APK(s).
5. ستجد APK داخل: `app/build/outputs/apk/debug/app-debug.apk`
6. انقل APK للهاتف وافتحه، ثم فعّل السماح بالتثبيت من هذا المصدر إذا طلب Android ذلك.
